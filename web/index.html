ExpertStream

Giant Mixture-of-Experts models don't use all their weights for each word. ExpertStream keeps the small core in RAM and streams in only the experts each token needs from your phone's storage.

Skill packs

Different topics tend to use different experts. A skill pack keeps the experts your tasks use on the phone and leaves the rest out. That is how a model bigger than your storage can still run. es_import -x already builds packs from a list of experts.

–of experts kept
–on the phone
–of 151 GB free

How a pack gets made: run the full model on sample prompts for a skill (on a computer or in the cloud), record which experts the router picks, and keep the ones that cover nearly all picks. When a prompt needs an expert that isn't on the phone, the engine has to use the closest one it has, which lowers quality, or fetch it from the cloud, which is slow. Recording these routing traces is a later step.

Old phones as accelerators

Can an old phone become an RTX 3050?

Not in speed. A phone can't gain memory bandwidth or compute through software. What old phones can add is storage and RAM for experts: several phones on Wi-Fi could each hold part of a model. Here is your phone next to an RTX 3050 (desktop, 8 GB).

Where the engine is

Done

  • Expert file format and a 4-reader flash loader, 1.75 GB/s measured
  • 2-bit NEON kernel, bit-exact with llama.cpp, 9.81 GB/s on 4× A78
  • Decode loop with expert cache and prefetch
  • Hugging Face download and GGUF importer, checked byte for byte on 3 real models

Next

  • Tokenizer read from core.gguf
  • Attention, router, norms, and Q3_K / Q4_K kernels
  • First real text from OLMoE-1B-7B on your phone

Later

  • Routing traces and skill-pack builder
  • Speculative decoding with a small draft model
  • Laptop build, then pooling several phones over Wi-Fi
