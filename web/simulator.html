ExpertStream Simulator

An MoE model too big for RAM, streamed expert by expert from flash on your phone. This page re-runs the es_run decode loop in the browser, timed with the numbers your phone measured in Steps 1 and 2. Change the cache and routing settings and watch where each token's time goes.

Weights are random and the router is synthetic. Flash and kernel speeds are your measurements.

The simulator assumes flash and compute don't slow each other down. On the phone they share memory bandwidth, so real runs will be somewhat slower.

Run the real engine

This page models the engine. To run the actual C code on your phone, paste this into Termux. Results are saved to step3_results.txt.

cd ~/Stream- && git pull && bash scripts/step3.sh

Keep the screen on with Termux in front. The first run writes a 6.3 GB test dataset, which takes about 15 seconds.

How a layer runs

attention matvec (big cores)
look up 8 experts in the RAM cache
  miss → read the file from flash (little-core readers)
start reading predicted experts for the next layer
wait for this layer's 8 experts
gate · up → SiLU → down on the big cores
