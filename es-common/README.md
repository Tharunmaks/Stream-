# es-common: shared DB schema/migrations (SQLite default, Postgres via DATABASE_URL), scrypt accounts, HS256 JWT (ES_JWT_SECRET, cookie es_session),
Expert One subscription read/write, plan limits, model library table + storage dir (ES_MODELS_DIR), es_bin() lookup of prebuilt engine binaries in ES_BIN_DIR,
and esmoe.py (Python MoE format/create/streamed inference/tiny torch trainer; no engine C source).
