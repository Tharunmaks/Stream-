ExpertCraft

Let Claude, ChatGPT, Cursor or any AI that speaks MCP build a language model from scratch, from 1 million up to 70 billion parameters. It designs the model, gets free training data, trains a BPE tokenizer, writes the PyTorch code, and trains on free GPUs (Google Colab, Kaggle) or your own machine.

1

Design

Pick a size. It chooses layers, width, heads and shows the exact parameter count, memory and training time.

2

Data

Streams free datasets (TinyStories, FineWeb-Edu, Wikipedia) or your own text, and trains a BPE tokenizer on it.

3

Train

One device, or many GPUs with FSDP. Saves often and resumes by itself when a free session ends.

4

Talk to it

Export to one weights file and chat with the model you made.

      Free compute
      
Where training happens

      
    
        
  • Your phone (Termux): tiny models and testing the pipeline. Slow but always available.
    • 
        
  • Google Colab free: 1× T4 GPU. Every project includes colab.ipynb, saving to Google Drive so it resumes.
    • 
        
  • Kaggle free: 2× T4 GPUs, about 30 GPU-hours a week. Every project includes kaggle.ipynb, which shards the model over both GPUs.
    • 
        
  • Rented GPUs: the same torchrun … --fsdp command scales to many GPUs for billions of parameters.
    • 
      

    

    

      Straight answer
      
About 70 billion parameters

      
Expert Craft designs, writes and can run training code for a 70B model (FSDP, sharded checkpoints, meta-device init, activation checkpointing). Training one properly needs about 1.1 TB of GPU memory and around 400,000 H100-hours, so no free service can do it. The free path: build and test the pipeline small, train 30M–1B models on Colab or Kaggle, and scale up when you have GPUs.

What the AI gets

    

      
ToolWhat it does

design_modelConfig for any size from 1M to 70B, with cost.

run_stepRuns data / train / export / sample, in the background for long jobs.

        
job_statusRunning or not, loss trend, best validation loss, checkpoints.

        
stop_jobStops training after saving a checkpoint.

        
connect_guideSetup snippets for every AI app.
