Paste the admin token your gateway printed when it started.

Where do I find the token?
  1. The gateway prints a link that signs you in by itself: …/dashboard#token=adm-…. Open that link.
  2. Or, on the machine running the gateway: 
    cat ~/.expertcloud/admin_token
  3. Tokens starting with join- are for worker nodes, and sk-expert- keys are for the API; neither signs in here.
  4. Lost it, or shared it by accident? Restart the gateway with --rotate-tokens to make new ones.
